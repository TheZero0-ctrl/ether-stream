# Ether

WIP desktop streaming app built with `Tauri + Rust + React + TypeScript`.

## Current Status

- Work in progress.
- Currently supports anime streaming (movies/other media may be added later).

## Development

```bash
pnpm install
pnpm tauri dev
```
